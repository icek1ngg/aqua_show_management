# AquaShow Management System

## Overview
ASMS is a web application for show management, ticket booking, PayOS payment, QR ticket generation, and check-in validation.

## Tech Stack
Frontend: ReactJS, Vite, Tailwind CSS  
Backend: Java Spring Boot, Spring Security, JWT  
Database: PostgreSQL  
Cache: Redis  
Queue: RabbitMQ  
Payment: PayOS  
Email: Gmail  

## Project Structure
- frontend/
- backend/
- docs/

## Main Features
- Authentication and authorization
- Show and schedule management
- Booking and payment
- QR ticket generation
- QR ticket validation
- Reports
